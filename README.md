# PlanX

Совместная доска для планирования в духе Miro: бесконечный холст, стикеры, текст, фигуры, стрелки, фреймы и библиотека иконок. Несколько человек могут работать на одной доске одновременно и видеть курсоры друг друга.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Пример доски открывается по умолчанию, новая доска создаётся кнопкой «Новая доска», а ссылку на неё даёт кнопка «Поделиться». Откройте ту же ссылку во втором окне, и изменения будут появляться в обоих.

## Сборка и продакшен

```bash
npm run build
npm start          # один процесс: сайт + синхронизация на порту 1234
```

Переменные окружения:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PORT` | `1234` | порт сервера |
| `DATA_DIR` | `./data` | папка, где хранятся доски (`<id>.bin`) |
| `VITE_SYNC_URL` | тот же хост, путь `/ws` | адрес сервера синхронизации, если он отдельно от сайта |

Есть `Dockerfile`: `docker build -t planx . && docker run -p 1234:1234 -v planx-data:/app/data planx`.

## Как устроено

```
src/
  model/      данные доски в Yjs: элементы, стрелки, отмена действий
  canvas/     отрисовка на <canvas>, геометрия, перенос текста
  editor/     инструменты, мышь, тачпад, клавиатура
  collab/     подключение к серверу, офлайн-кэш в IndexedDB, курсоры участников
  icons/      набор иконок (генерируется из assets/icons)
  ui/         React-интерфейс вокруг холста
server/       сервер синхронизации (протокол y-websocket) и раздача сайта
```

- **Данные отдельно от отрисовки.** Доска хранится в документе [Yjs](https://yjs.dev) (CRDT). Каждый элемент это отдельный `Y.Map`, поэтому если один человек двигает стикер, а другой меняет его цвет, сохранятся оба изменения.
- **Отмена своих действий.** `Ctrl+Z` отменяет только ваши изменения, а не чужие. Перетаскивание или изменение размера отменяется одним шагом.
- **Офлайн.** Доска кэшируется в IndexedDB браузера, открывается без сети, а изменения догоняют сервер, когда связь вернётся.
- **Сервер** хранит каждую доску в памяти, пока на ней кто-то есть, и сохраняет на диск через секунду после изменения.

## Нововведения

Пробные функции лежат в `src/labs` и включаются переключателями в меню доски: «Нововведения». Сейчас там экспорт в PNG, экспорт в PDF, авторасположение, замок, поиск по доске (Ctrl+F), общий таймер, реакции, лазерная указка (K), «Следовать за участником» с «Все ко мне», курсоры участников, шпаргалка по клавишам (?), замена двойным кликом (смайл, иконка или фигура меняется на соседнюю, и в инстансе тоже) и «Текст не слипается» (текст, ставший выше, отодвигает текст прямо под ним). Их кнопки стоят на панели у правого края, устроенной как панель инструментов: кнопки переставляются удержанием, сама панель двигается и укорачивается за края. Функция, которую решили не оставлять, убирается вместе со своим файлом в `src/labs` и строчками, где вызывается `labOn`.

## Иконки

Исходные SVG лежат в `assets/icons`. Чтобы заменить или добавить иконки, положите туда SVG 24×24 и выполните:

```bash
npm run icons
```

Скрипт пересоберёт `src/icons/icons.json`. Цвет `#333333` становится цветом иконки на доске, поэтому иконки перекрашиваются и подстраиваются под тёмную тему.
