# PlanX: передача проекта Кодексу

Собрано 30.10.2026 из заметок и обсуждений с Claude. Правила работы — в `AGENTS.md`, структура папок — в `README.md`. Здесь то, чего нет в коде: история, решения, риски и планы.

## Коротко о проекте

PlanX — доска для планирования в духе Miro, интерфейс на русском. Владелец — Женя (Zheka, GitHub `Evverr`), не разработчик: пишет задачи, пробует результат руками и решает, что оставить.

- Репозиторий: https://github.com/Evverr/PlanX
- Продакшен (только сайт, без синхронизации): https://planx-ten.vercel.app
- Стек: TypeScript + React, отрисовка на `<canvas>`, данные в Yjs (каждый элемент — свой `Y.Map`), свой сервер синхронизации `server/` (протокол y-websocket, доски хранятся файлами `DATA_DIR/<id>.bin`, в продакшене он же отдаёт `dist/`), офлайн-кэш y-indexeddb, курсоры и выделения через awareness.
- Проверки: `npm test`, `npm run typecheck`, `npm run build`.

## Главные решения (и почему)

- **Совместная работа с самого начала** (20.10). Любое изменение данных должно сливаться у нескольких людей сразу. Синхронизацию в двух окнах проверяли в headless Chromium.
- **Данные отдельно от отрисовки**: `src/model` ничего не знает о canvas.
- **Новые функции — пробные** (24.10). Всё новое кладётся в `src/labs` с переключателем в меню доски «Нововведения» (`LABS` в `src/labs/labs.ts`). Женя пробует и решает, оставить или убрать. Сейчас там: export, pdf, tidy, lock, search, timer, reactions, laser, follow, cursors, keys, wishlist, comments, objects, multi, swap.
- **Сначала план, потом код.** Женя выбирает функции из списка, прежде чем их делать. Большие идеи предлагай списком с номерами.
- **Стартовая страница «Мои доски»** (PR #3, `src/shelf`). Задумка Жени: папки стоят на деревянных полках (не блокноты); внутри папки квадратные плитки досок с миниатюрой всего содержимого и вложенные папки. Без `?board=` открывается полка (`?folder=id` — внутри папки). Логотип на доске возвращает в её папку. Списки досок и папок лежат в `localStorage` (`planx-boards`, `planx-folders`), на сервере списка нет.
- **Шаблоны** (PR #4, `src/shelf/templates.ts`). Зелёная папка «Шаблоны» создаётся один раз на браузер (флаг `planx-templates`): Канбан-доска, Ретроспектива, План проекта. Содержимое подкладывается через путь `planx-copy:<id>` в `App.tsx`.
- **Аудиозаметки и картинки** хранятся прямо внутри доски строкой (data URL), отдельных файлов нет. Папка `data/` в `.gitignore`, доски на GitHub не попадают.
- **Иконки**: свой набор 24×24 «Outline Icon Bold» в `assets/icons`, только заливка (в Figma обводки переводить в контуры до экспорта). `npm run icons` пересобирает `src/icons/icons.json`, цвет `#333333` становится цветом иконки. Обводочные пути раньше превращались в сплошные кляксы.
- **Mac Жени не различает регистр имён файлов.** `Labs.tsx` рядом с `labs.ts` уже ломал сборку (переименовали в `LabsLayer.tsx`).
- Логотип: зелёная точка `#22C55E` (PR #7).

## Известные проблемы

- **Vercel без VPN не открывается** (25.10). На iPad в Safari без VPN — «сервер перестал отвечать», Mac открывает через VPN. Похоже, провайдер блокирует vercel.app; код не виноват. Свой домен на Vercel, скорее всего, тоже будет заблокирован (те же IP). Настоящее решение — другой хостинг (ниже). Женя смотрит превью PR через VPN.
- **На Vercel нет сервера синхронизации**, там работает только сайт. Совместная работа по-настоящему идёт только локально (`npm run dev`) или на своём сервере.

## Ревью приложения (27.10) — риски по важности

Объём на тот момент: ~13,5 тыс. строк в ~90 файлах, 15 файлов тестов, 9 зависимостей. Сложность средняя и выше.

1. **Нет входа и прав доступа.** Кто знает ссылку на доску, может её читать и править.
2. **Список досок только в браузере.** Почистил браузер или сменил устройство — папки и полки пропали (доски на сервере остаются).
3. **Нет резервных копий.** Доски лежат файлами на одном диске.
4. **Картинки и аудио внутри доски** — доска с фото тяжёлая и медленно открывается.
5. **Большие файлы**: `editor.ts` и `renderer.ts` по ~1100 строк, их трудно менять.

Сильные стороны: данные отделены от отрисовки, Yjs правильно сливает правки, простой сервер (один процесс), готовый `Dockerfile`, тесты, точные версии библиотек.

## Хостинг (оценка 27.10, цены примерные, не проверены)

Нужен маленький VPS в России, приложение запускается целиком из `Dockerfile`:
- Timeweb Cloud или Beget VPS: ~200–400 ₽/мес (1 ядро, 1–2 ГБ). Хватит на десятки людей одновременно.
- Selectel: ~300–600 ₽/мес. Yandex Cloud: от ~1000 ₽/мес.
- Домен .ru: ~200–900 ₽/год, HTTPS бесплатно через Let's Encrypt.

## Что дальше (предложения, Женя ещё не выбрал)

Крупное делать по шагам, один PR на шаг:
1. **Переезд на VPS**: инструкция по шагам для Жени + автоматические резервные копии досок.
2. **Список досок на сервере** вместо `localStorage` (с переносом старых списков).
3. **Вход и права доступа**: владелец, ссылка «только смотреть» / «можно править».
4. **Картинки и аудио отдельными файлами** на сервере, в доске только ссылка.
5. **Разделить `editor.ts` и `renderer.ts`** на модули без изменения поведения.

Из обзора конкурентов (25.10) ещё нет: голосования точками, истории версий, экспорта в SVG, презентации по фреймам (частично сделано позже в «Нововведениях» — сверяйся с `LABS`). Позиционирование: быстрая доска без лимита «3 доски бесплатно» (он есть у Miro, Mural, Lucidspark, FigJam). SDK tldraw платный для коммерции, так что свой движок — плюс.

Идеи «для настроения» (22.10, Женя не выбирал): стикер «шлёпается» с отскоком при появлении, приподнимается с тенью при перетаскивании, плавные курсоры коллег, мягкий зум, стрелка «прорисовывается», удаление «тает», приветствие на пустой доске, тихие звуки с выключателем, конфетти за ✅.
